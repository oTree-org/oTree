About

oTree is an open-source platform for web-based interactive tasks, such as:

  • Psychology experiments
  • Multiplayer games
  • Auction markets
  • Strategy games
  • Dynamic questionnaires or surveys
  • Assessments and tests

oTree has been used in over 2700 academic publications.

Why use oTree?

Versatile

Few frameworks are as user-friendly yet versatile as oTree. Build anything from a game of tic-tac-toe to a live auction market.

Easy

oTree limits itself to the most basic programming concepts: if-statements, loops, simple functions, lists, and dicts.

Ideal for learning

oTree is a fun way to learn programming. And it is a great hands-on addition to courses in subjects like economics or psychology.

Build experiments without code

Use OTAI to build sophisticated research studies without writing any code. It's engineered for reliability and can deliver research-grade apps. More about OTAI here.
